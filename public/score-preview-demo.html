这一版的口径

  • 尺寸内容区 600 × 600 = 62 左轨（内核常量 RD.LEFT，留给符干/符尾）+ 476 网格 + 62 右留白，左右严格等宽；内核滚动条隐藏（滚轮 / 触控板照常可滚）。
  • 已砍右侧「简谱对照带」（内核 RD.RIGHT = 108）整体裁掉 —— 连续预览下它本来就是空的一块（可勾「简谱对照」才画）。
  • 进度条内核竖向进度条 #progBar 已接上（宽 10、贴预览区右缘，落在右侧那 62 留白里）：跟着播放 / 暂停 / 复位走，按住可上下拖动跳转（拖动时自动暂停并弹时间气泡）。壳里那条「把它藏掉」的覆盖规则已删，内核逻辑一行没改。
  • 外置播放播放按钮在卡片外面——卡片正上方、与卡片同宽的一条横条里，左对齐。父页这颗按钮是内核 #btnPlay 的镜像：点它 = 点内核那颗，文案由内核同步回来，谱面上不再浮任何控件。
  • 复用内核直接以 iframe 承载内核单文件 composer.html，渲染 / 排版 / 音名 / 播放全部是内核本尊，未重写。
  • 单栏连续预览（内核 paged=false），不排双栏、不分页。
  • 悬浮音名保留内核的悬浮音位轴；pointer-events:none 关掉「点某一列试听」。
  • 数据入口内核导出的 JSON 自带简谱原文 source，组件据此「重新生成琴谱」——这就是加载用户乐谱的通道。
